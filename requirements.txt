# Embeddings for Semantic_Matcher. This set is a three-way squeeze -- change one pin
# and check the other two:
#   - torch 2.2.2 is the newest PyTorch on Intel (x86_64) macOS, so nothing here may
#     require more than that;
#   - transformers >=4.52 refuses to torch.load a .bin checkpoint on torch <2.6
#     (CVE-2025-32434), and S-PubMedBert-MS-MARCO ships .bin, not safetensors --
#     so 4.51.3 is the ceiling until torch moves;
#   - litellm requires tokenizers>=0.21, which the previous 4.44.2/0.19.1 set could
#     not satisfy. 4.51.3 can.
# Verified: embeddings are bit-identical to the old pins (max abs diff 0.0), so the
# upgrade does not move Semantic_Matcher's resolutions or the features they stage.
# torch must be pinned explicitly -- left unpinned it resolves to a bleeding-edge
# release that initializes models on the meta device and breaks transformers 4.51.3's
# .to() move ("Cannot copy out of meta tensor").
